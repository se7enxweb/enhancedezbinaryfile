  from ekked's pull request #11.

  Gujarati, Kannada, Malayalam, Punjabi, Odia, Hausa, Amharic, Yoruba, Igbo, isiZulu, Somali and isiXhosa, from
  ekked's pull request #10.
- Added: Russian, Catalan, Serbian (Cyrillic and Latin), Bulgarian, Lithuanian, Portuguese (Portugal) and Afrikaans
  translations, from ekked's pull request #9.
- Added: Translations into eighteen more administration languages: Hindi, Korean, Bosnian, Lower Sorbian, Estonian,
  Irish, Icelandic, Greenlandic, Latvian, Hungarian, Maltese, Romanian, Albanian, Slovak, Slovenian, Japanese, Greek
  and Finnish, from ekked's pull request #8.
- Added: Swahili (Kenya) translation, from ekked's pull request #6.
- Fixed: Translations that contradicted their language guide: wrong meanings, glossary breaches, forms of address,
  typos and English left in the text, from ekked's pull request #7.

1.0 - 1.1  Compatible with ez4.1.0

- Changed all instances of eZDOMDocument to DOMDocument since lib/ezxml went
  away.

- Added a filecheck template operator which will do a file_exists so it's
  possible to display a link only if the file exists.  This new functionality should
  be backward compatible to existing collected information.
  syntax: {if eq($attribute.data_text|filecheck,true)}

- Added the check to collectinfo to only send the multi-part mail if there
  is a file attachment.
